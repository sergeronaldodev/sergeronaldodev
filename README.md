- 💬 **Parlons de** : React, Next.js, Node.js, TypeScript, TailwindCSS, SEO technique et optimisation Core Web Vitals.
- 👯 **Collaboration** : Ouvert aux projets innovants, opportunités freelance et collaborations professionnelles.
